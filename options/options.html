테마

패널 UI 색상 테마를 선택합니다. 자동은 DevTools 자체 테마 설정을 따라갑니다.

요청 목록

패널 요청 목록에 표시할 항목과 최대 보관 개수를 설정합니다. 최대 개수를 넘으면 오래된 요청부터 제거됩니다.

단축키

현재 사이트의 Nova Debug on/off 를 토글하는 단축키입니다.

서버 연동 설정

확장이 debug 조회 요청(?fetch={id})을 보낼 Fetch 경로는 호스트별로 아래 "호스트" 표에서 설정하세요 (비워두면 기본 경로를 사용합니다).

서버 ext.tokens 항목에 위와 같은 값을 넣어야 협상/조회가 통과합니다. 비워두면 기존처럼 IP만으로 opt-in됩니다.

호스트

헤더 주입을 허용할 호스트와 IDE 연동 정보를 한 곳에서 관리합니다. 체크된 호스트에만 X-Nova-Debug 요청 헤더를 주입합니다(팝업의 사이트별 스위치와 같은 값을 공유합니다). 헤더 주입(캡쳐)은 기본적으로 Nova Debug 패널 탭이 표시된 동안만 수행되며, "오픈 캡쳐"를 체크한 호스트는 DevTools가 열려 있는 동안 항상 수행됩니다 (변경은 다음 DevTools 오픈부터 적용). trace/파일 경로는 서버 프로젝트 루트 기준 상대경로이므로, Local Path 에는 그 상대경로가 이어붙을 로컬 프로젝트 루트 경로를 입력하세요. 매핑이 없는 호스트는 IDE 링크 없이 텍스트로만 표시됩니다. Fetch 경로가 비어 있으면 기본 경로를, 토큰이 비어 있으면 위 공통 토큰을 사용합니다.

💡 Chrome: 파일 열기 확인창 없애기

Chrome 은 IDE 링크(phpstorm:// 등 커스텀 프로토콜) 실행 시 "항상 허용" 선택지 없이 매번 확인창을 띄웁니다(devtools 확장에서의 실행은 사용자 제스처 없는 탐색으로 간주되기 때문). 아래 정책을 적용하면 위 표에서 체크한 호스트+프로토콜 조합에 한해 확인창 없이 바로 열립니다. Firefox 는 확인창에서 "항상 허용"을 선택하면 되므로 별도 설정이 필요 없습니다.
